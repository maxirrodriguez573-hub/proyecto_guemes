¿Para qué va a hacer el bot? 
El bot es para registrar recibo de compras y guardar tanto los datos de la compra como la foto del recibo

¿Para quien va a hacer el bot?
Para el tesorero 

¿Qué va a hacer el bot?
El bot va a guardar fotos del recibo de la compra y quizás la compra y la descripción de la compra para luego registrarlo en una base de dato
¿Qué datos va a guardar? 
Los datos van a ser:

OBLIGATORIO
- Fecha recibo
- Monto

AUTOMÁTICO
- Fecha actual

OPCIONAL
- Descripción
- Cambiar fecha

SQL:

TABLA GASTO
- gasto_id -> PK / AI
- telegram_usuario_id -> NOT NULL, INT
- categoria_id (FK) -> NOT NULL, INT, FK (CATEGORIA.categoria_id)
- comercio_id (FK) -> NOT NULL, INT, FK (COMERCIO.comercio_id)
- fecha -> NOT NULL, TEXT 
- monto -> NOT NULL, REAL 
- descripcion NULLEABLE, TEXT
- recibo_file_id NOT NULL, TEXT

TABLA CATEGORIA (Ferretería, librería, supermecado, limpieza)
- categoria_id PK / AI
- nombre NOT NULL, TEXT, UNIQUE

TABLA COMERCIO (112, el enano, Lore, Carrefour)
- comercio_id PK / AI 
- nombre NOT NULL, TEXT, UNIQUE
- dirección NULLEABLE, TEXT (FUTURO) 
- horario NULLEABLE, TEXT(FUTURO)



FUNCIONES DE LAS TABLAS 

TABLA CATEGORIA 
Esta tabla debe tener datos fijos y el usuario no tendría que añadir los datos pero está la opción.

- AGREGAR CATEGORIA ( nombre ) 
- ELIMINAR CATEGORIA
- OBTENER UNA CATEGORIA
- OBTENER LA LISTA DE CATEGORIAS

TABLA COMERCIO 
Esta tabla tiene que tener los datos principales del comercio para que después se puedan comparar entre sí. 
El usuario debería gestionar esta tabla.

- AGREGAR COMERCIO ( nombre, dirección (opcional), horario (opcional) )
- ELIMINAR COMERCIO
- OBTENER UN COMERCIO
- OBTENER LA LISTA DE LOS COMERCIOS

- MODIFICAR NOMBRE DEL COMERCIO
- MODIFICAR DIRECCIÓN DEL COMERCIO
- MODIFICAR HORARRIO DEL COMERCIO ( formato fecha y fecha actual por defecto )


TABLA GASTO
Tabla principal donde el usuario lo usará siempre y con datos obligatorios.

- AGREGAR GASTO ( tel_usuario_id , cat_id, comer_id, fecha, monto, descr., recibo_id )
- ELIMINAR GASTO 
- OBTENER UN GASTO
- OBTENER LA LISTA DE GASTOS

- MODIFICAR UN GASTO
